About AntiSnipe Hook

Built for fair launches.

Every token launch on a DEX faces sniper bots in the first blocks. AntiSnipe Hook solves this at the protocol level — inside the pool itself. No admin keys. No off-chain setup. No trust required.

✦ afterInitialize()
Records the exact launch block when pool is created. The protection timer starts here — immutable and on-chain.
✦ beforeSwap()
Intercepts every swap and calculates the correct fee based on blocks elapsed. Fully automatic. No human needed.
✦ getProtectionStatus()
Anyone can verify which protection phase a pool is in. Complete transparency for your community.
AntiSnipeHook.sol
// Fee phases (in pips) uint24 constant MAX_FEE = 900000; // 90% uint24 constant HIGH_FEE = 500000; // 50% uint24 constant MID_FEE = 100000; // 10% uint24 constant NORMAL_FEE = 3000; // 0.3% // afterInitialize: record launch function afterInitialize(...) { poolLaunchBlock[poolId] = block.number; emit PoolLaunched(poolId, block.number); } // beforeSwap: apply decay fee function beforeSwap(...) { uint256 elapsed = block.number - launchBlock; if (elapsed <= 1000) fee = MAX_FEE; else if (elapsed <= 5000) fee = HIGH_FEE; else if (elapsed <= 10000) fee = MID_FEE; else fee = NORMAL_FEE; }
