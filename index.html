01 — What is AntiSnipe Hook

A smart shield
for every launch.

AntiSnipe Hook is a custom Uniswap V4 Hook contract that plugs directly into any liquidity pool at creation time. It automatically applies a time-decaying fee — starting extremely high to crush bot snipers, then smoothly dropping to normal trading fees once the launch window has passed.

No admin keys. No configuration. No manual steps. Just deploy, attach, and launch safely.

V4 Uniswap V4 Hooks

Built on Uniswap V4's Hook mechanism — a powerful new primitive that lets developers intercept and customize pool behavior before and after swaps, at zero extra trust assumption.

⛓ Fully On-Chain

Every decision is made on-chain. No oracle, no off-chain bot, no multisig. The block number is the only input needed — it's trustless by design.

⚡ X Layer Native

Deployed on X Layer — a low cost, high throughput EVM chain — making this protection accessible to every new token project without prohibitive gas costs.

04 — How to Use

Three steps to a
protected launch.

Any token project can plug AntiSnipe Hook into their Uniswap V4 pool. No code changes to your token. Just one extra field in the PoolKey.

01
Deploy your ERC20 token on X Layer

Launch your token contract normally on X Layer Testnet or Mainnet. No special modifications needed — AntiSnipe Hook works with any standard token.

02
Create a V4 Pool with the Hook address

When initializing your Uniswap V4 pool, add the AntiSnipe Hook address to the PoolKey hooks field. The Hook activates the moment the pool is created.

hooks: 0xDB7D45ea5B0F1C4F7176dd0fF98099e55e8424E4
03
Launch. The Hook handles everything.

afterInitialize() records your launch block. Every swap hits beforeSwap() which calculates the correct fee automatically. Your community trades fairly from day one.

04
Monitor via getProtectionStatus()

Anyone can check the current protection phase on-chain at any time. Share this with your community so they know exactly when full open trading begins.

getProtectionStatus(poolId) → "PHASE 1 - Anti-Snipe Active (90% fee)"
PoolCreation.sol — usage example
// Step 1: Define your PoolKey // with AntiSnipe Hook address PoolKey memory key = PoolKey({   currency0: address(yourToken),   currency1: address(WOKB),   fee: 3000,   tickSpacing: 60,   hooks: 0xDB7D45...8424E4 }); // Step 2: Initialize the pool // afterInitialize() fires here poolManager.initialize(   key,   INITIAL_SQRT_PRICE ); // Step 3: Check protection status hook.getProtectionStatus(poolId); // → "PHASE 1 - Anti-Snipe (90%)" // Step 4: After 100 blocks... hook.getProtectionStatus(poolId); // → "PHASE 4 - Normal (0.3%)" // ✅ Done. Fully automatic.
05 — Implementation Steps

How it's built
under the hood.

For developers who want to understand the technical architecture or fork and extend the Hook for their own use case.

01
Setup
Environment & Tools
Get your development environment ready with Remix IDE and MetaMask for browser-based deployment.
  • Open remix.ethereum.org
  • Install MetaMask extension
  • Add X Layer Testnet (Chain ID: 195)
  • Get free OKB from faucet
02
Core Contracts
Two Key Functions
The Hook implements two Uniswap V4 callback functions that handle all the launch protection logic.
  • afterInitialize() — records launch block
  • beforeSwap() — applies decay fee
  • getPoolId() — unique pool identifier
  • getProtectionStatus() — readable phase
03
Fee Logic
Block-Based Decay
The fee calculation is a simple if/else on blocks elapsed — no math libraries, no oracles, no external dependencies.
  • 0-10 blocks → 900000 pips (90%)
  • 10-50 blocks → 500000 pips (50%)
  • 50-100 blocks → 100000 pips (10%)
  • 100+ blocks → 3000 pips (0.3%)
04
Deployment
Deploy & Verify
Deploy using Remix with MetaMask's Injected Provider. Verify source code on X Layer Explorer for judge transparency.
  • Compile with Solidity 0.8.24
  • Deploy via Injected Provider
  • Verify on X Layer Explorer
  • Test via AntiSnipeTest.sol
05
Testing
Live Simulation

  • simulateLaunch() — start the timer
  • simulateSwap() — watch fee change
  • whatFeeAtBlock() — preview fees
  • getSwapLogs() — full audit trail
